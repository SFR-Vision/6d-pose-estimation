\begin{abstract}
Estimating the 6D pose of objects from RGB images is a challenging problem due to sensitivity to lighting conditions, textureless surfaces, and occlusions. In order to overcome these constraints, we suggest a two-phase framework that uses RGB input to estimate object pose before expanding the model to use depth information for increased robustness and accuracy.
RGBD based methods have shown strong performance by using both color and depth information, but their effectiveness relies on how well these two complementary modalities are combined. In this two stage framework, we evaluated the two models on the LineMOD dataset. We first introduce a pure RGB baseline, where objects are localized using a YOLOv8 detector, and a ResNet50 network predicts object rotation, whereas a small CNN network predicts depth, while the remaining translation components are recovered analytically using the pinhole camera model. Based on this baseline, we extend our framework to an RGBD model by using depth data to improve geometric understanding and pose accuracy. Results indicate that the proposed RGB-based method provides a good monocular baseline, and that extending the framework to RGBD provides notable gains in pose accuracy and robustness due to the availability of explicit geometric information.
\end{abstract}
